# SMM v0.2 — проверка перед включением

По умолчанию OXANA_SMM_ENABLED не задан: API закрыт. Не включать на рабочем сервере.
Миграция russian-postgres/smm-001.sql не применяется автоматически. Сначала резервная копия и отдельная тестовая БД в РФ; проверить роль приложения и выдать минимальные права на схему, таблицы и последовательность журнала. Не использовать роль владельца БД для runtime.

Проверки: npm ci и npm run build в корне; в server — npm ci, npm run typecheck, npm run test:smm, npm test. Затем интеграционные тесты с тестовым PostgreSQL: чужое сообщество/пост недоступны, создание версии атомарно, устаревшее подтверждение возвращает 409, редактирование сбрасывает актуальное согласование, конкурентное подтверждение и редактирование сериализуются. Ни один запрос не публикует контент.

API /api/smm: GET status, GET/POST communities, GET/POST posts, PATCH posts/:id, POST posts/:id/approve (version и confirm:true), POST posts/:id/publish (403). Все методы требуют JWT и allowlist. Изоляция пока по owner_id из проверенного JWT, без командных workspace. Бюджетная таблица — задел, не механизм списания. Нет платных вызовов. Интерфейс пока не связан с API. Нет медиа, источников, очереди, MAX/VK и фактчекинга. Согласование здесь относится только к текстовому черновику, не к разрешению внешней публикации.

Не добавлять реальные идентификаторы групп, секреты и пользовательские данные в публичный GitHub.
