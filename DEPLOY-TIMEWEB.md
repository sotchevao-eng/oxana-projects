# Деплой на Timeweb Cloud (App Platform)

## Подготовка (уже в репозитории)
- Сборка: `npm run build`
- Папка сборки: `dist`
- SPA fallback: `public/_redirects` (копируется в `dist`)
- Переменные: см. `.env.example`

## Панель Timeweb Cloud

1. Откройте https://timeweb.cloud/ → **App Platform** → **Создать**.
2. Тип: **Frontend** → **React** (Node.js 20+).
3. Подключите GitHub-репозиторий этого проекта, ветка `main`.
4. Включите сборку по последнему коммиту (автодеплой).
5. Настройки приложения:
   - Команда сборки: `npm run build`
   - Директория сборки: `dist`
   - Путь до директории проекта: оставьте пустым (корень)
6. Переменные окружения (обязательно, как в локальном `.env`):
   - `VITE_SUPABASE_URL`
   - `VITE_SUPABASE_ANON_KEY`
7. Нажмите **Заказать** и дождитесь успешного деплоя на вкладке **Деплой**.

## Ссылка для клиентов
После деплоя технический домен вида `*.twc1.net` будет на карточке приложения и во вкладке **Настройки**. Эту ссылку можно сразу отправлять клиентам.

## Свой домен
1. Зарегистрируйте домен (в Timeweb или у другого регистратора).
2. В App Platform → приложение → **Настройки** → привязка домена.
3. Пропишите DNS (A / CNAME), как покажет панель.
4. Дождитесь выпуска SSL.

Документация: https://timeweb.cloud/docs/apps/deploying-frontend-apps  
Привязка домена: https://timeweb.cloud/docs/apps/upravlenie-apps-v-paneli#privyazka-domena
